## AgentOptions

`Options` is a type alias (`type Options = AgentOptions`) kept for backward compatibility —
both names are interchangeable.

```go
type AgentOptions struct {
	// API Authentication
	APIKey      string
	AccessToken string

	// API Endpoint Configuration
	BaseURL string

	// Provider Selection (anthropic, bedrock, vertex)
	Provider APIProvider

	// Model configuration
	Model             string
	SmallFastModel    string // Haiku-class model
	BigModel          string // Opus-class model
	MaxThinkingTokens int
	MaxTokens         int

	// System prompt
	SystemPrompt string

	// Tool configuration
	AllowedTools    []string
	DisallowedTools []string

	// Permission handling
	PermissionMode PermissionMode

	// Resource limits
	MaxTurns     int
	MaxBudgetUSD float64
	TimeoutSecs  int

	// Session management
	Resume               string
	ContinueConversation bool
	ForkSession          string

	// MCP servers
	MCPServers    MCPServers
	MCPConfigPath string

	// Hooks
	Hooks *HookRegistry

	// Plugins
	Plugins map[string]SDKPluginConfig

	// Agent definitions
	Agents map[string]AgentDefinition

	// Sandbox settings
	Sandbox *SandboxSettings

	// File management
	FileCheckpoints  bool
	AddDirectories   []string
	WorkingDirectory string

	// AWS Bedrock / Google Vertex / Proxy configuration
	Bedrock *BedrockConfig
	Vertex  *VertexConfig
	Proxy   *ProxyConfig

	// Environment variables passed to the CLI subprocess
	Environment map[string]string

	// CLI configuration
	CLIPath string

	// Behavior flags
	Debug       bool
	Verbose     bool
	NoTelemetry bool
	SkipOAuth   bool

	// Output configuration (text, json, stream-json)
	OutputFormat string

	// Legacy: Interactive mode (for backward compatibility)
	Interactive bool
}
```

`PermissionMode` is a string type with named constants such as
`claude.PermissionModeBypassPermission`; see `types.go` for the full set.

## Content blocks

```go
type ContentBlock interface{ contentBlock() }

type TextBlock struct {
	Text string
	// ...
}
type ThinkingBlock struct{ /* ... */ }
type ToolUseBlock struct {
	ID    string
	Name  string
	Input map[string]interface{}
}
type ToolResultBlock struct {
	ToolUseID string
	Content   string
	IsError   bool
}
```

| Type | Description |
|------|-------------|
| `SystemMessage` | System events: `init`, `hook_started`, `hook_response` |
| `AssistantMessage` | Claude's response with content blocks |
| `UserMessage` | User input or tool results |
| `ResultMessage` | Final summary: session ID, cost, duration, token usage |
| `StreamEvent` | Raw streaming events |
| `TextBlock` | Plain text response |
| `ThinkingBlock` | Extended thinking (internal reasoning) |
| `ToolUseBlock` | Tool invocation with name, ID, and input |
| `ToolResultBlock` | Tool execution result |

session, or [Examples](/claude-go/examples/) for complete, runnable programs that use them.
